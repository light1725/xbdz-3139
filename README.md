# 0010903139 触控板控制工程 (对接 0010903029 电源板)

## 一、硬件芯片与引脚映射 (SC92F8411B SOP16)

| 信号名称 | MCU 引脚 | 芯片功能 | 软件配置与用途 |
| :--- | :--- | :--- | :--- |
| **DAT** (CN1 Pin 2) | **Pin 16** | **P0.0** | 单线通信发送引脚，强推挽输出，空闲高电平 |
| **K2 KEY** (照明键) | **Pin 13** | **P2.0 / TK8** | 赛元触控通道 **TK8**，独立控制照明灯 |
| **L2** (KEY2_LED 照明灯) | **Pin 7** | **P1.3** | 强推挽输出，低电平点亮，跟随 K2 照明状态 |
| **K4 KEY** (风速+延时) | **Pin 10** | **P2.5 / TK13** | 赛元触控通道 **TK13**，控制风速档位与 15 分钟延时 |
| **L4** (KEY4_LED 风速/延时灯) | **Pin 8** | **P1.5** | 强推挽输出，低电平点亮，开风机常亮，延时 500ms 周期闪烁 |

## 二、通信协议 (对接 3029 电源板)

- **底层时序 (Fsys = 12MHz)**:
  - 引导码: 9.1ms 低电平 + 4.5ms 高电平
  - 数据位: 0.8ms 低前导 + PWM 高 (0: 0.7ms, 1: 3.7ms)
  - 收尾码: 0.8ms 低电平，总线恢复空闲高电平
  - 周期: 402ms
- **4字节数据帧 (MSB 先发)**:
  - 关机待机: `00 00 00 00`
  - 单开照明: `08 28 00 30`
  - 单开 1 档: `00 00 02 02`
  - 单开 2 档: `00 00 03 03`
  - 单开 3 档: `00 00 04 04`
  - 3 档 + 照明: `08 28 04 34`
  - 延时模式: 持续发送当前风速帧，本地倒计时 15 分钟结束后发送关机帧

## 三、业务控制逻辑

1. **上电自检**: L2 与 L4 同时点亮 1 秒后熄灭，进入关机待机。
2. **K2 触摸键 (照明)**: 独立翻转照明开关，L2 (P1.3) 同步点亮/熄灭。
3. **K4 触摸键 (风速与延时)**:
   - **短按 (松手触发)**: 高(3) -> 中(2) -> 低(1) -> 关(0) 循环，L4 (P1.5) 同步点亮/熄灭。
   - **长按 2 秒**: 启动 15 分钟延时模式 (L4 灯 500ms 周期闪烁)，长按生效后松手不误切档。
   - **延时下换档**: 短按 K4 切换风速时，延时倒计时保持运行，不重置不打断。
   - **到期关机**: 15 分钟倒计时结束自动关机，L4 熄灭，发送待机帧 `00 00 00 00`。
